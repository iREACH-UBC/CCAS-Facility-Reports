# Creating a Report Generating Script

## Getting Calibrated Sensor Data

To generate a report for a facility, you will first need to
obtain calibrated data for the facility's sensors. For
information on how to obtain this data, see
[this explanation](../explanation/sensor_data.md) on sensor data.

## Processing the Data, Saving Processed Data

You will need to process your data to a format recognized by the
CCAS report generator, if it is not already processed. For
information on the processed file format, the functions you can
run to process a dataset, and how to save/read processed data,
see [this explanation](../explanation/processed_data.md).

## Generating a Report

For information on generating a report, see this
[explanation](../explanation/generate_report.md).
