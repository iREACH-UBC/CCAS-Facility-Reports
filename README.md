# Getting Started

## Accessing the Code

To edit and run the code in this repository, clone the
repository locally or open a Github codespace.

## Generating Reports

To generate a report using an existing script, visit
[this tutorial](docs/tutorial/generating_reports.md)
for a guide on how to do so. To create your own report
generating script, see this [how-to guide](docs/how-to/create_report_generating_script.md).
